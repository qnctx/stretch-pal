# 🌸 StretchPal — 你的桌面拉伸提醒伙伴

每天 9:00、11:00、13:00、15:00、17:00，一个可爱的横幅会从屏幕右侧飘过，用风趣的方式提醒你**站起来活动**。

> 久坐是慢性杀手，但 StretchPal 是可爱的杀手 🐢💃

## ✨ 效果

- 粉色可爱横幅从屏幕**右侧飘入 → 横穿 → 左侧飘出**（约10秒）
- **不抢焦点、不打断工作** — 它静静飘过，你随时点击它就消失
- 20 条随机风趣文案，每次弹出都有新鲜感
- 系统托盘常驻，右键可手动测试或退出

## 🚀 使用方式

### 双击运行

```
双击 run.bat
```

首次运行会自动 `pip install pystray Pillow`（很小，几秒就好）。

### 开机自启

把 `run.bat` 的**快捷方式**放到 Windows 启动文件夹：

```
Win + R → shell:startup → 粘贴快捷方式
```

### 退出

右键系统托盘的心形图标 ❤ → 退出

## 📋 文件说明

| 文件 | 用途 |
|------|------|
| `stretch_pal.py` | 主程序 |
| `messages.py` | 风趣文案库（随便改） |
| `run.bat` | Windows 启动脚本 |
| `requirements.txt` | Python 依赖 |

## 🔧 自定义

- **修改提醒时间**：编辑 `stretch_pal.py` 顶部的 `REMINDER_HOURS`
- **添加更多文案**：编辑 `messages.py`，加到 `MESSAGES` 列表里
- **修改颜色**：编辑 `stretch_pal.py` 顶部的颜色常量

## 📦 依赖

- Python 3.6+
- `pystray` — 系统托盘图标
- `Pillow` — 托盘图标绘制（pystray 依赖）
- `tkinter` — Python 自带，无需安装

## 🐛 如果托盘图标不出来

可能是 pystray 没装好。程序会自动退化到右下角一朵小花 🌸，右键它也能控制。
